# 八分钟项目演示

1. **0:00～1:00，说明主题。** 动态N/D变化时，编译成本、缓存容量与计算收益如何权衡。展示中文工作台与五种策略。
2. **1:00～2:00，观察编译。** 选公共表达式示例，运行后看IR合并、常量折叠和真实Java代码。
3. **2:00～3:00，组合归约。** 选行方差模板，说明均值广播、中心化与最终N×1输出；用1,2,3手算2/3。
4. **3:00～4:00，形状与窗口。** N/D跨度设32，导入multiaxis轨迹；分析recorded-combined展示1163条来源清晰的批次形状。
5. **4:00～5:00，矩阵乘法。** 导入examples中的A/B手算矩阵，展示58、64、139、154，查看生成的分块代码与三轴守卫。
6. **5:00～6:00，重复实验。** 打开随包五fork报告，同时讲计算、冷请求、区间、CV与GC/JIT记录，保留不利或高波动结果。
7. **6:00～7:00，完整真实数据。** 展示三套数据、122列KDD99映射与逐批数值校验；演示进度条和取消状态。
8. **7:00～8:00，查看证据。** 在实验浏览中筛选已完成/失败/取消；打开原始CSV、metadata和当前应用摘要。

范围说明：这是CPU/double的编译实验平台，矩阵乘法有独立入口，不提供GPU、自动微分或分类训练。当前表中679项本地检查、三套全量回归与五fork实验都有可打开的记录。
