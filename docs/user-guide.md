# 中文工作台使用指南

[返回首页](../README.md) · [功能说明](completed-features.md)

双击根目录 `Chinese.bat`。完整JDK17及以上可运行，启动脚本会切到正确的项目根目录。JDK23.0.2使用同一入口。

## 第一次运行公式

1. 左侧选择“可组合归约·行方差”或“激活函数融合链”。
2. 设置N/D；有导入矩阵时，形状由文件决定。
3. 选择执行策略，点击“运行当前输入”。
4. 依次查看计算图、生成Java、运行事件、内核缓存和运行结果。
5. 点击“导出运行结果”，保存逐请求CSV、完整末次输出和生成代码。

中间行归约沿列广播；最终行归约输出N×1。详细合法函数见[DSL](dsl-reference.md)。

## 导入数据与轨迹

“导入矩阵”接受无表头数值CSV，偏置可选择单行CSV或全零。“导入形状”接受rows/cols/repeat，也接受带rows/cols列的原始请求或批次CSV。导入轨迹只规定形状，回放数值按固定种子生成。

“清除数据”恢复生成输入；“重置会话”清空引擎和会话结果。“保存工程”保留公式与参数，外部矩阵和轨迹须单独导入。

## 二维形状与复用窗口

在“参数设置”里调热度窗口、预测请求预算、N/D跨度、缓存、预算、热点阈值和复核间隔。N跨度0表示二次幂，D跨度0表示固定列宽。正数为固定跨度，例如都填32。

“轨迹分析”可直接选择 `examples/traces/recorded-combined.csv`。结果在“轨迹与复用”标签，点击“查看报告”打开完整频次图和逐请求估计。1163条随包轨迹来自真实文件读取日志，来源说明在examples/traces。

## 策略重复对比

点击“对比执行策略”，设置独立进程次数、预热与测量遍数。建议先用3次熟悉流程，再用5次保存重复实验。界面显示实际进程、阶段、行数和批次；报告包含区间和噪声记录。

“回放动态负载”用于当前策略。长轨迹超过交互内存预算时，自动改为逐批执行一个冷序列和一个测量序列，不同时持有所有矩阵；状态和结果会明确标出。

## 测试完整真实数据

点击“测试随包数据”，选择Covertype、Poker或KDD99，再选前65,536行或全部记录，设置重复次数。该按钮使用当前公式与引擎参数，逐种策略从文件开头读取真实特征；不使用N/D输入框或随机轨迹。

从源码仓库克隆时仅有quick样本，请使用发行附件中的完整datasets，或通过命令行 `--input quick.csv --label none` 先测样本。

## CPU矩阵乘法

点击“矩阵乘法”。选择固定种子输入时设置N/K/M；选择导入时连续提供A和B两个无表头CSV，实际形状从文件读取。选择三轴区间或精确守卫，设置独立fork，然后查看三种模式的报告。导入A的列数必须等于B的行数。

## 实时进度、取消与浏览

底部进度条显示组号、策略、已处理行、批次数和阶段。未知总量的文件显示不定进度，直到有实际总量；不使用估算百分比冒充准确进度。

“取消任务”中断当前工作进程，保留已完成记录并标记取消；Java编译调用正在执行时，可能等到当前调用返回后响应。失败或取消不会显示成完成。

点击“实验浏览”，输入文字筛选名称、类型、状态和JDK；选一行打开报告或目录。运行结束后自动刷新，也可手动刷新。日期列明确采用UTC，来自实验元数据。

图中折线只显示计算时间；含编译/验证/调优的完整请求时间请看运行结果或报告。缓存命中率也要结合派发策略和运行事件解释。
