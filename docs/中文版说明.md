# 中文版使用说明

[首页](../README.md) · [工作台指南](user-guide.md)

双击Chinese.bat启动；Linux/macOS使用sh Chinese.sh。标题、按钮、模板、事件、结果、进度与实验浏览均为中文，合法DSL函数和Java代码保留稳定技术名称。

2.4包含可组合行归约、N/D二维守卫、窗口复用估计、独立重复的置信区间和噪声报告、实时进度、实验浏览，以及CPU矩阵乘法。全部入口与检查见[功能与验证](../FEATURES.md)。

本机JDK23.0.2可运行目标Java17的项目。随包679项本地检查和性能记录来自Linux/JDK17.0.20，环境在元数据中明确记录。字体及许可位于assets/fonts。
