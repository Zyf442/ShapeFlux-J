# 2.4功能操作与实现

[返回首页](../README.md) · [功能与验证](../FEATURES.md)

## 1. 实测轨迹与窗口复用估计

打开工作台的“轨迹分析”，选择 `examples/traces/recorded-combined.csv`。也可直接选择dataset导出的 `batches.csv` 或会话的 `requests.csv`；读取器按列名定位rows/cols，其他字段不参与形状分析。紧凑格式为 `rows,cols,repeat`。

随包三套真实数据日志一共1163批，39种精确形状。`provenance.json`保存源日志位置、SHA、行总数与提取方式。combined文件仅按Covertype→Poker→KDD99拼接三个独立实验，不代表单个生产会话。

滑动窗口默认128个请求。每个形状族在窗口内的次数除以窗口实际长度得到频率；频率乘预测请求预算（默认256）得到预计复用次数。超过窗口未出现的记录退出估计，旧热度不会永久累计。再次到达间隔记录的是两个请求序号之差，单位为请求数，不是墙钟秒或不同键的栈距离。

`--horizon`在2.4中表示预测请求预算。配置字段为兼容旧工程仍保留原标识，语义以2.4说明为准。软预算、热点阈值与实测收益复核继续生效。

## 2. 二维守卫

`--row-bucket 0`使用原有二次幂N区间；正数指定固定N跨度。`--col-bucket 0`固定D；正数指定D跨度。比如两个跨度都设32，输入40×70落入N=33～64、D=65～96。

生成代码检查两个轴的四个边界、输入长度和输出长度。固定列宽时可展开列循环；跨列宽区间使用实际D循环。它不补零，也没有把不同D的偏置向量混用。验证覆盖当前输入以及预算允许的小型区间角点；发布测试另核验边界外输入会拒绝。

## 3. 重复实验与置信区间

“对比执行策略”可设置独立fork、预热和测量次数；“测试随包数据”与“矩阵乘法”可设置fork。上限10，单次不报告方差。报告包含各fork原始值、95%均值区间、样本标准差和CV。

独立单位是工作进程，不是同一JVM中的请求。区间假定各fork统计量近似独立且t方法适用；少量或偏斜样本需谨慎解释，不把区间写成单次请求的覆盖范围。CV≥10%只作提示，结果不被删除。

## 4. 合法函数和可组合归约

新增sin、cos、expm1、log1p、pow、floor、ceil、square。新增rowmax、rowmin、rowvar，并允许rowsum/rowmean/Softmax/归一化在中间表达式中组合。中间行标量沿该行D列广播，最终根为行归约时紧凑输出N×1。

编译器在行阶段之间融合逐元素子图，为行阶段使用按D分配的临时数组并跨N行复用。普通逐元素图仍使用直接融合路径。维度相关的归约不作为普通标量常量折叠。

## 5. 实时进度和实验浏览

工作进程在引擎计时外写原子进度快照，父进程每约200毫秒读取。底部显示当前策略/进程序号、实际行数、批次数与阶段。总量未知的自定义文件显示不定进度，不编造百分比；结束时以实际行数收敛。

“实验浏览”只读取小型元数据，支持目录、类型、状态和JDK筛选。选择一行可打开报告或原始文件夹；失败与取消记录仍显示真实状态。CLI `browse`生成可搜索的离线HTML快照。

长轨迹超过交互回放的内存预算时自动进入逐批重放路径，只保存当前输入；执行当前策略的一个冷序列和一个测量序列，进度与报告均区分阶段。数值按种子重建，不冒充原始业务内容。

## 6. CPU矩阵乘法

`MatrixInput`定义A[N,K]、B[K,M]和C[N,M]。三种模式为REFERENCE、GENERIC、BLOCKED；独立三重循环为参考。分块代码采用16行、32个K、32个M的块，每个输出仍按K递增相加。

精确守卫固定N/K/M；区间守卫在三轴使用二次幂边界。缓存上限可在引擎API中设置，命令行实验使用8。每个新编译内核先与当前输入的独立参考核验，再执行；报告保存实际Java代码、输出矩阵与逐轮原始值。

仅支持无转置C=A×B，不包含alpha/beta或偏置。A、B与C各不超过800万元素，单次N×K×M不超过5亿，输出不能与输入数组别名。所有限制在进入计算前检查。
