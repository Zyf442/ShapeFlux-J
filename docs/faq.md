# 常见问题

[返回首页](../README.md) · [操作指南](user-guide.md)

## 它是一键生成算子优化吗？

选择或编写项目支持的公式后，“运行当前输入”会自动完成计算图优化、融合代码生成、编译、执行和数值校验。输入语法和算子集合见 [DSL说明](dsl-reference.md)。系统不会自动发明任意新算子，也不提供通用Java程序优化。

## 三个入口使用什么数据？

| 入口 | 实际输入 |
|---|---|
| 运行当前输入 | 当前已导入矩阵；没有导入时生成固定种子输入 |
| 回放动态负载 / 对比执行策略 | 按所选形状轨迹生成的固定种子随机数值 |
| 测试随包数据 | 三套数据之一的实际特征，按批流式读取 |

## 为什么第一次运行慢？

它包含编译器初始化、Java源码编译和内核验证。重复请求可能复用缓存。看完整请求总时间时应保留这些成本；界面折线只显示内核计算时间。

## 为什么自适应策略没有接纳专用内核？

预测复用收益、编译预算和实测收益都影响准入。候选没有足够收益时会被拒绝。查看运行事件中的“暂缓特化”“候选收益探测”“拒绝专用内核”；被接纳后也可能在周期复核中撤销。

## 为什么解释执行反而更快？

一次完整遍历包含冷编译成本，算子、批量和JVM状态都会影响结果。项目保留这些结果，帮助定位编译成本何时能被摊销，而不是保证每个负载加速。

## 能用我的RTX 4060吗？

项目当前使用CPU和双精度数组，GPU不参与计算；可以在装有该显卡的普通笔记本运行。选择完整数据测试时依次执行工作进程，按批读取，不一次加载整个特征矩阵。

## 校验通过等于分类准确率高吗？

“校验通过”表示编译内核输出与参考算子实现一致。项目不训练森林类型、网络连接或手牌分类模型，标签不参与算子输入。未测量这些任务的模型准确率。

## 中文乱码或找不到数据怎么办？

完整解压并保留 `assets/fonts` 与 `datasets`，使用 `Chinese.bat` 或 `Chinese.sh` 启动。字体优先使用系统中文字体，缺少时自动读取随包字体。单个矩阵导入请使用quick CSV，不要把批次清单当作矩阵。

## 工程文件保存哪些内容？

`.sfxproj` 保存公式、策略、单次形状、内置合成负载和引擎参数，不嵌入真实矩阵或外部轨迹。再次打开工程后可重新导入输入数据。
