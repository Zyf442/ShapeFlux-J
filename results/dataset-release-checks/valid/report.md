# ShapeFlux-J 真实数据集测试报告

每种策略的每次重复使用独立 Java 进程，从文件开头顺序读取同一批真实数值。批次顺序循环为 33,40,48 行，偏置为零。每个工作进程只保留当前批次，逐批与参考解释器校验。

单次文件遍历包含首次编译请求，没有额外预热；中位数和第95百分位覆盖本次全部批次。引擎耗时包含编译、内核验证、收益探测和复核，排除文件读取及外部参考校验。遍历总耗时包含读取、特征摘要计算、引擎执行、参考校验与逐批记录，不含 Java 进程启动和最终报告生成。
